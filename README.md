# Mebel360 Hisobchi AI

GitHub Pages uchun tayyorlangan Mebel360 Hisobchi versiyasi.

## Asosiy fayl
- `index.html` — sayt ochilganda ishlaydigan asosiy Hisobchi AI versiyasi.
- `versions/` — avvalgi hisobchi variantlari.
- `assets/` — logo va PWA ikonkalari.
- `tools/` — Excel/Python yordamchi modul (GitHub Pages bu Python faylni server sifatida ishlatmaydi).

## GitHub'ga joylash
1. GitHub'da yangi repository oching, masalan `Mebel360-Hisobchi`.
2. Shu papkadagi fayl va papkalarni repository ildiziga yuklang.
3. Commit qiling.
4. GitHub: `Settings` → `Pages` → `Deploy from a branch`.
5. Branch: `main`, Folder: `/ (root)` → `Save`.
6. Bir necha daqiqadan keyin GitHub Pages havolasi ochiladi.

## Telefon/PWA
`manifest.webmanifest` va `service-worker.js` qo'shilgan. GitHub Pages orqali ochilganda telefon brauzerida ilova sifatida o'rnatish imkoniyati bo'lishi mumkin.

## Keyingi bosqich
Play Market uchun keyin Android `.aab` qobig'i tayyorlanadi. Avval GitHub Pages'da funksiyalarni tekshirish tavsiya etiladi.
